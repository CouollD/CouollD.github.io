# アイコン画像の置き場

`<キャラid>.png` の名前でここに置くと、結果画面(LINE風チャット)のアイコンが絵文字から画像に差し替わる。ファイルが無いキャラは絵文字のまま(フォールバック自動)。

- ヒロイン: `101.png` 〜 `110.png`(idは data/gamedata.js の HEROINES 準拠)
- 友達(男側): CHARACTERS の id(例: `1.png`, `2.png`)
- 推奨: 正方形・256px程度。円形に切り抜かれる(object-fit:cover)ので顔を中央に

他の画面(布陣・友達一覧など)への展開は未対応。展開するときは result.html の `avatarHTML()` と同じ規約を使うこと。
