会話システムの比較（2026-09-30〜10-02）

作成 2026-10-02　更新 2026-10-03

同じ場面（乾杯のあと約5分、ヒロイン3人＋友達2人、自分＝塾バイト・実家・文化系）を、方式を変えて作って遊んだ記録。 進め方は 試作で比べる進め方、台詞の量は 台詞の量とAI。

きっかけ（9/30）

遊べる版（A）を遊んだ感想： - 会話はつながっているようで、つながっていない（同じ話題でも、前の発言を受けていない） - 仕組みが肥大化していく - 「話題」という概念がネック - グノーシアより難しい

方式の一覧

案 元ネタ 台詞 プレイヤーの手 台詞の量（デモ）
A グノーシア グノーシア 部品の組み立て 話題を出す／乗る・掘る・茶化す 部品 約290行

遊んだ感想（10/1）

  • 会話がつながって見える：B・D
  • 会話っぽい：E・C。特定の話題について「掘り下げるか、流すか」を選ぶところがそれっぽい
  • F：内容は良い。ただし取り分けは全員に向けるもの
  • B：トークン消費が課題。みんなが別々の方向に話を進めていて、受け答えになっていない
    • 原因はAIではなく進行の作り（エンジンが「この子が、話題を出した人に向けて話す」を1人ずつ決め、AIは空欄を埋めるだけ）。専用モデルでも直らない
  • G/H（ミックス）：ボタンが多い

案I の改訂（10/2）

1回目

C＋E を土台に、目立ちゲージ（喋る→上がる）と、気づきの札（グラス空など、出ている間にタップ）を足した。 - 感想：CEがいい（自分が話題を選べている感じ）。ただし C は正解が決まりすぎ、E は割り込まない損と目立ちすぎる危険が見えない - 気配りは、グノーシアの嘘のように「一定のタイミングで気づける」と面白い - 料理が運ばれてくる場面がほしい

2回目

  • 選択肢のタイマーが消える不具合を直した
  • 「自分の話（話題を変える）」は不自然 → やめて、自然につながる返しだけにした
  • 気づけるかを「空気読み＋黙っている分」で決めるようにした
  • 取り分けは調べて作り直した（料理と飲み物の気配り）
  • 感想：グラスは確定で気づける？→何かが高いときだけでもいい／連絡先交換は投票のようなフェーズがほしい

3回目

  • 会話が途切れたら「話題を出すか、待つか」（返しの出し方）
  • スマホの札はあからさますぎる → 退屈そうな表情に変え、話しかけるか好きそうな話題で戻す
  • 取り分けてもらったら「ありがと」が言える
  • 連絡先は全員と交換が筋 → 最後は「帰り道、だれの隣を歩くか」をせーので出す
  • ログを3案（ログUI）
  • 感想：いい感じ。ログはチャット＋振り返りの複合がよさそう。最後に「せーの」で出し合うのは不自然 → 合コンの終わり方 を調べた

4回目

  • ログに「複合」（話題ごとのカード＋中はチャット）を足して標準にした
  • 終わり方を作り直した：締め → 全員と交換 → 二次会か帰るか（駅まで送る）→ 翌朝のお礼LINEが結果発表

5回目

  • 気配りで会話が切れたら、直前に話していた人が話を戻す（「……なんの話だっけ」）
  • 翌朝のグループLINEに自分もお礼を送れる
  • 話題を4つ足した（地元・休みの日・お酒の強さ・最近ハマってるもの）。途切れたときに出せる話題は、夜ごとに入れ替わる3つまで
  • やりながら覚えるヒント（初めて出てきた仕組みだけ）
  • 方針：本編の会話はこの案Iに変える（10/2 決定。予定への反映は日曜夜）

6回目（10/3）

  • 遊びすぎて話が読めてしまった → 自分の設定を3通りから選べるようにした。手札（自分の経験）が変わるので、口を挟める所と話が合う子が変わる
    • A：塾バイト・文化系・実家（あおいと合う）
    • B：居酒屋バイト・フットサル・一人暮らし（ゆなと合う）
    • C：パン屋の朝番・軽音・学生寮（めいと合う）
    • 各設定とも、手札の出番は10か所前後。台詞はサブエージェント（Sonnet）が書き、AI臭の規律で直した
  • 話題を2つ足した（朝型・夜型／カメラロール）。途切れたときに出せる話題は9つから3つ

自動で通した結果（I 3回目）

遊び方 起きたこと
程よく喋る 目立ちは最大50前後。話す相手次第で結果が分かれる
喋り続ける 70で「めっちゃ喋るじゃん」、90で「しゃべりすぎな」。結果に「よく喋る人」
黙り続ける 話題が変わるたびに「お前も何か言えよ」。気づきは全部見える
大事な話の途中で動く あおいの話が止まり、好感度と空気が下がる
